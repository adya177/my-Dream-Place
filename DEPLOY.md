# Deploying My Dream Place

The Vercel site is only the React frontend. The Express API and MongoDB need to be reachable on the internet for login and listings to work on the public site.

## Deploy the API

1. Create a MongoDB Atlas database and copy its application connection string. Allow the API host to connect in the Atlas network settings, and replace the password placeholder in the connection string.
2. In Render, create a Blueprint from this repository and select `render.yaml` (or create a Web Service with root directory `server`, build command `npm install`, and start command `npm start`).
3. Set `MONGODB_URI` on the API service to the Atlas connection string. `JWT_SECRET` is generated by the Blueprint. Wait for `/health` to report `{"status":"ok","database":"connected"}`.

## Connect Vercel to the API

1. In the Vercel project serving `my-dream-place-jet.vercel.app`, add `VITE_BASE_URL` for Production and Preview, using the Render service URL (for example, `https://my-dream-place-api.onrender.com`) with no trailing slash.
2. Redeploy the frontend so Vite embeds the new API URL in its production bundle.

The ignored local `client/.env` is not uploaded to Git and does not configure Vercel. Do not set the production API URL to `localhost`; that would refer to each visitor's own computer. The local MongoDB installation is likewise only reachable from this laptop.
